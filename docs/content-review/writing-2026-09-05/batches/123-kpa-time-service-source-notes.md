## Reader question and result

The module explains which event starts a deadline, how the recipient and delivery channel affect that event, how to calculate and preserve the deadline, and when restoration is a separate remedy. It distinguishes the organ's processing period from the party's time to act. Six authored sections replace the former layered lesson and unfinished exercises. Legacy layer fields remain concise orientation; exercise arrays are empty.

The completed example is a separate ordinary KPA proceeding begun in 2026. PURDE is stipulated as an appropriate channel, the party has a valid electronic-delivery address in the address database, and no representative has been appointed. This is not a MOS application or a proceeding with a different mandatory response channel. Its result is a timely response, not proof of the substantive condition or a permit decision.

The module does not equate a wrongly served letter with a validly served letter whose deadline was missed. A hospital record can establish hospitalization without itself establishing inability to act or absence of fault. The paragraph therefore states that additional causal assessment explicitly.

## Document roles and integration limits

- `authority-summons`: the actual wezwanie establishes the selected response period.
- `delivery-proof`: evidence about the incoming letter, with the correct recipient and event. The existing guide is an explanation of that evidence category, not an assertion that its example is an official PURDE form.
- `response-letter`: the actual signed response, distinct from its working chronology.
- `dispatch-proof`: evidence of the outgoing submission. In the selected electronic exchange this includes the receipt evidence obtained by the sender, not just an outbox entry.
- `power-of-attorney`: the separate instrument relevant to who should receive service. No representative is invented in the example.
- `deadline-obstacle`: an expressly described evidence overview, not a single mandatory certificate. No universal hospital-document packet is prescribed.
- `administrative-appeal`, `procedural-order`, `procedural-complaint`: distinct documents in the restoration explanation; none is invented as an event in the selected timely-response example.
- `upo`: explicitly the existing MOS-specific guide used for contrast. It is not relabeled as PURDE receipt evidence.

There is no invented dedicated catalog entry for a restoration request or a PURDE receipt format. The existing main provision panel can remain within 35–49b and 57–60. A repealed 39² displayed within the source sequence must remain marked repealed; the module does not assign it a current rule. Supporting 14 and 63 are typed inline references.
