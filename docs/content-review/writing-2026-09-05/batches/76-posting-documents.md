# Posting document guide preparation

Pending implementation after batch 75. No document guide is accepted by this source note.

## PIP declaration source and layout, 12.09.2026

Root opened the actual public [Biznes.gov.pl service](https://www.biznes.gov.pl/pl/portal/ou1328) in a browser after the web extractor could not open it. The service describes submission electronically with Profil Zaufany or a qualified signature, or delivery of a paper original. It explicitly says not to wait for an acceptance letter because PIP does not issue one. The service is free; representation can entail separate costs. These are administrative instructions, not a work-permit decision.

Expanded Documents and followed the published [Polish PDF](https://zaplecze.biznes.gov.pl/files/document_attachments/2876/O_wiadczenie_pracodawcy_deleguj_cego_pracownika_na_terytorium_RP.pdf). Downloaded the original to .reference/pip-posting-form.pdf. Inspected all six physical pages using Poppler renderings. The PDF has five portrait numbered form pages and a separate landscape worker-data annex. Metadata says August 2020; it is the file linked by the current service, not a newly dated 2026 form. It has no interactive fields. The header uses an old office address; use the current service contact destination when explaining submission.

Visible structure:

1. Sender state and posting arrangement, instructions, employer identity and foreign tax/insurance identifier.
2. Employer contact/correspondence details, number of workers, dates, service type, contact-person role.
3. Contact-person details and document storage address in Poland. Conditional Polish user-employer block.
4. Conditional foreign user-employer block and representative details.
5. Legal basis, attachments, person submitting, date and signature. Worker-data annex; representation and fee documents only if a representative is appointed.
6. Landscape annex, repeated for each work address: address plus worker name, birth date and citizenship rows.

A future guide must separate the worker-data annex submitted with the declaration from employment, time and payroll records retained for possible inspection. A1 and a work permit are not universal attachments to this declaration. Fictional specimens must omit identifying information and explicitly describe their selected-field scope. Do not reproduce the old office address as current instructions.

Legal field and deadline basis: [Posting act, Dz.U. 2025 poz. 1682](https://eli.gov.pl/api/acts/DU/2025/1682/text/O/D20251682.pdf), art. 24(1–6), art. 25 and art. 26. Read directly by root. Changes to declaration information require a notice within seven working days. The [PIP change-notice explanation](https://www.pip.gov.pl/dla-pracodawcow/pytania-i-odpowiedzi/co-w-sytuacji-kiedy-dane-zawarte-w-zlozonym-oswiadczeniu-o-delegowaniu-pracownika-na-terytorium-rp-ulegly-zmianie) says to identify the previous declaration and each changed fact, with before/after information; its linked form is auxiliary and open.

## Other destinations

Use the final batch-75 comparison to select useful specimens; avoid creating empty guides for every mentioned record.
